# 游戏开发组 · 组说明

> 《High》程序与架构产出小组。核心原则：按模块开发、高内聚低耦合、每模块完成必测试。

## 职责

- 引擎与工程搭建（Vite + TypeScript + React + Phaser 3）。
- 游戏逻辑开发：资源 / 建筑 / 科技 / 小人 AI / 阶段切换 / 离线结算 / 存档。
- 场景层开发：网格地图、小人动画、寻路。
- 构建与部署（itch.io → Vercel / Railway）。
- 设计参考资料的整理（reference/）。

## 产出物位置

```
游戏开发组/
├── src/          游戏源码（入口、game/ 逻辑、scene/ 场景、ui/ 面板）
├── reference/    关键资料备份（数值表、竞品截图）
└── build/        构建产物（gitignore）
```

## 技术栈（已定稿，见 docs/01_技术选型.md）

Vite + TypeScript + React 18 + Zustand + Tailwind CSS + Phaser 3 + easystarjs + break_infinity.js

## 开发规范（详见 docs/03_目录结构.md）

1. **分层**：`game/`（纯逻辑，不依赖 React/Phaser）→ `scene/`（Phaser 渲染）→ `ui/`（React 面板）。
2. **数值集中**：所有数字常量在 `game/systems/balance.ts`，调平衡只改这一个文件。
3. **配置 JSON 化**：建筑 / 科技 / 阶段配置放 `game/data/*.json`，加内容不改代码。
4. **每模块必测试**：Vitest，写完代码 → 写测试 → 跑通 → git commit（`feat(模块): 一句话`）。
5. **分支**：`main` 为主，里程碑打 tag：`v0.1-m0`、`v0.2-m1`...
