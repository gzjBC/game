> 调研日期：2026-09-17

## 一、给你的快速结论

- **技术栈建议**：挂机游戏本质是"数字增长 + UI + 存档"，几乎不需要物理/碰撞/美术，**纯 HTML+JS/TS（或 React）+ localStorage 就够了**，这正好匹配你的前端/后端工程能力，也是作品集里最容易做完的一类。想做得更顺手再上 **Cocos Creator（TS，可导微信小游戏/H5）** 或 **Godot（导 Web）**。
- **必须先补的"设计内功"**：挂机游戏不是写代码难，是**数值曲线**难。成本几何增长 `Cost(n+1)=Cost(base)×rate^n`、产出线性/指数混合、转生（Prestige）循环、离线收益公式——这些看完 GDC 那场演讲 + 数值曲线视频就能入门。
- **你的 Agent 背景是降维打击**：自动挂机、离线结算、数值平衡、存档防作弊、 even 接一个 LLM 当游戏内 NPC/解说，都是你熟的事。
- **最小可上线路径**：3 天做一个 Cookie Clicker -like → 加 localStorage 存档 → 加离线收益 → 传 itch.io（免费、网页直接玩）。
