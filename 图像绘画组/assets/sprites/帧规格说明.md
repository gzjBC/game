# 帧规格说明 · 原始人像素小人 Sprite Sheet

> 《High》· 图像绘画组产出 · 供 游戏开发组 接入
> 版本：v1.0（2026-09-18）

## 1. 文件清单

| 文件 | 内容 | 帧数 |
| --- | --- | --- |
| `villager_high_walk.png` | 默认配色（自然原始人）行走循环 | 4 方向 × 4 帧 = 16 |
| `villager_high_idle.png` | 状态变体：idle（灰） | 16 |
| `villager_high_pathfinding.png` | 状态变体：pathfinding（蓝） | 16 |
| `villager_high_moving.png` | 状态变体：moving（绿） | 16 |
| `villager_high_harvesting.png` | 状态变体：harvesting（橙） | 16 |
| `villager_high_returning.png` | 状态变体：returning（深蓝） | 16 |

> 各状态变体与默认 sheet 共用同一套行走帧，仅整体换配色，保证状态可辨、动画节奏一致。
> 预览图 `_preview_*.png` 仅供人工检查，非游戏资源。

## 2. 单帧规格

- **尺寸**：32 × 32 像素 / 帧
- **底色**：透明（RGBA，alpha=0）
- **锚点（origin）**：**脚底中心 (16, 31)**——即 32×32 画布最底行正中。游戏内放置/对齐均以该点贴地。
- **造型**：原始人（深肤色、乱发、兽皮裙、赤脚），纯色块像素风格，无描边。

## 3. 帧序（Sheet 布局）

每张 sheet 为 **128 × 128**，4 行 × 4 列，行 = 方向、列 = 帧序号：

```
列 →   帧0        帧1        帧2        帧3
行0   down_0     down_1     down_2     down_3     （下：正面，有脸）
行1   left_0     left_1     left_2     left_3     （左：侧面，脸朝左）
行2   right_0    right_1    right_2    right_3    （右：侧面，脸朝右）
行3   up_0       up_1       up_2       up_3       （上：背面，纯后脑勺）
```

- **帧索引**（Phaser frame number）= 行 × 4 + 列，即 0..15。
- **行走循环语义**：帧0 站姿 → 帧1 迈左腿（左腿前/右腿后，右臂前摆）→ 帧2 过渡站姿 → 帧3 迈右腿（右腿前/左腿后，左臂前摆）。
- **循环播放建议**：0 → 1 → 2 → 3 → 0……（相邻帧衔接自然，无跳跃）。

## 4. 方向说明

| 方向 | 行 | 说明 |
| --- | --- | --- |
| down | 0 | 正面朝向镜头，可见眼睛与嘴 |
| left | 1 | 左侧面，脸朝左 |
| right | 2 | 右侧面，脸朝右（= left 水平镜像） |
| up | 3 | 背面，只见后脑勺（长发覆盖） |

## 5. 接入建议（Phaser 3）

```js
// 1) 加载任一 sheet（5 个状态 sheet 结构完全相同，可共用一份帧配置）
this.load.spritesheet('villager', 'assets/sprites/villager_high_walk.png',
  { frameWidth: 32, frameHeight: 32 });

// 2) 按 方向行 × 帧列 注册动画（示例：向下行走）
this.anims.create({
  key: 'walk-down',
  frames: this.anims.generateFrameNumbers('villager', { start: 0, end: 3 }), // 行0
  frameRate: 6,
  repeat: -1,
});
// walk-left  : frames 4..7   （行1）
// walk-right : frames 8..11  （行2）
// walk-up    : frames 12..15 （行3）

// 3) 锚点：脚底中心（贴地）
sprite.setOrigin(0.5, 1);

// 4) 状态换肤：切换 texture 到 villager_high_{state}.png 即可，
//    动画 key 与帧序号完全不变（5 个 sheet 帧布局一致）
sprite.setTexture('villager_pathfinding');
```

## 6. 坐标系约定（给开发组）

- 图像坐标：左上角为 (0,0)，x 向右、y 向下。
- 行走碰撞盒建议：以脚底锚点为底边，取约 12×10 px（x: 10..21, y: 21..31）的矩形即可贴合小人主体。
- 缩放：`setScale` 整数倍放大（如 3x）可保持像素锐利（Phaser 默认 nearest 采样）。
