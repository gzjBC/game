# 图像绘画组 · 组说明

> 《High》美术与视觉产出小组。当前阶段以免费素材占位为主，不追求原创美术。

## 职责

- 游戏内所有**视觉内容**：像素小人、建筑 tile、场景地形、UI 图标、特效。
- 音效 / BGM 的收集与管理（非核心，后期再做）。
- 素材的整理、命名、版本管理，与开发组交接。

## 产出物位置

```
图像绘画组/
└── assets/
    ├── sprites/   像素小人 / 建筑 tile / 场景元素
    ├── audio/     BGM / 音效
    └── fonts/     像素字体
```

## 当前阶段任务

- **里程碑 0 / 1（现在）**：不需要自己画图。用 Kenney 免费包或纯色方块占位，先把玩法跑通。
- **里程碑 2（村庄雏形）**：需要 32×32 像素小人，4 方向走路帧（用 Aseprite / LibreSprite 画，或继续用 Kenney 现成小人）。

## 协作规范

1. 素材文件命名：`类型_名称_状态.png`，如 `worker_cave_walk_down_1.png`。
2. 新素材放入对应子目录后，在 `项目记忆.md` 的进度记录里登记。
3. 素材改动不提交游戏代码逻辑；反之代码逻辑改动不依赖素材（用占位图开发）。
