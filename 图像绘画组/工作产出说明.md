## 2. 规格摘要

- **单帧**：32×32 px，透明底（RGBA），纯色块像素风。
- **帧数**：4 方向（down/left/right/up）× 4 帧行走循环 = 16 帧/张。
- **锚点**：脚底中心 (16, 31)，贴地对齐。
- **方向布局**：sheet 行序 down=0 / left=1 / right=2 / up=3；列序为帧 0..3（0 站姿 → 1 迈左腿 → 2 过渡 → 3 迈右腿）。
- **right 方向** = left 水平镜像（同一套侧面帧，保证左右对称）。
- **up 方向** = 背面（纯后脑勺），down = 正面（眼/嘴可见）。
- **状态配色**：idle 灰 / pathfinding 蓝 / moving 绿 / harvesting 橙 / returning 深蓝；5 张 sheet 与默认 sheet 帧布局完全一致，切换 texture 即可换状态，动画配置零改动。
- **造型**：原始人（深肤色、乱发、兽皮裙、赤脚），手臂用阴影肤色与身体区分，行走帧带腿脚交替与手臂摆动。

## 3. 生成与复现

```bash
cd 图像绘画组
python3 generate_pixel_villager.py
# 依赖：Python 3 + Pillow（pip install Pillow）
```

脚本以字符网格模板定义躯干（正/侧/背三视图），程序化生成腿脚/手臂逐帧摆动参数，再按 5 套调色板渲染输出 6 张 sheet + 2 张预览图，内置自检（尺寸/帧数断言）。重复运行输出完全一致，可复现。
