# 《High》

> 一个可视化的挂机 / 放置类（Idle / Incremental）经营网页游戏。
> 从一个山洞开始，看着原始人一步步建起村庄、小镇、城市、国家，最终冲出地球到太空殖民。

## 这是什么

- 品类：可视化放置经营（对标 CivIdle / 开罗游戏 / A Dark Room）
- 平台：浏览器优先（PC + 手机浏览器）
- 技术栈：Vite + React + TypeScript + Phaser 4 + Zustand

## 怎么玩

打开网页后，小人会自动前往浆果丛、树林和石堆采集。玩家通过生火、招募、建造茅草房与仓库、研究制陶和火耕，把原始营地发展成村庄。关掉网页后，游戏会按上限结算离线收益。
