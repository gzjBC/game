## 0. 文档定位

本文档**不拍板**。用户明确说"设计方向未定"，主策划的职责是：
1. 把"挂机游戏加肉鸽道具"这个想法拆成 5 个可对比的候选方案；
2. 每个方案讲清楚开发量、肉鸽感、与挂机节奏匹配度、数值风险；
3. 给出主策划的推荐，但最终选哪个由用户拍板。

**硬约束（不可推翻）：**
- 不推翻六阶段弧线、技术栈、三层架构。
- 不推翻 04e 已定的 500h 时长分解（道具作为其中一部分，不另起炉灶）。
- 不推翻 04_总览 §1.13 已冻结的"v1 科技树纯线性"——如果某方案要求 v1 就做分支，列入待裁决。

## 1. 设计张力：挂机游戏加肉鸽为什么难

在出方案前，必须先讲清楚一个根本矛盾——不然所有方案都是空中楼阁。

| 挂机游戏的核心 | 肉鸽游戏的核心 |
| --- | --- |
| **稳定可预期的增长** | **每局不一样的随机** |
| 玩家接受当前存档继续玩 | 玩家死了重开、追求"这局 build" |
| 数值平滑曲线 | 随机组合产生强力 build |
| 回来看到"东西变多了" | 回来看到"这局运气好不好" |

**把这两者直接捏在一起会出事**：
- 道具掉得太随机 → 玩家觉得"这局运气不好，重开吧"——但挂机玩家不重开，他们会弃坑。
- 道具掉得太线性 → 那就不叫肉鸽，叫"又一个科技树"。

**所以主策划的立场：肉鸽元素必须"轻"，不能破坏挂机的稳定感。** 具体走哪条路，是本文 5 个候选要回答的。

## 2. 通用框架（不依赖具体方案）

这一节是"无论选哪个方案都要定的东西"。

### 2.1 道具类型清单

| 类型 | 说明 | 例子 | 占比建议 |
| --- | --- | --- | --- |
| 属性增益 | 某资源采集 +X% | 浆果采集 +10% | 40% |
| 倍率增益 | 全局或某阶段 ×Y | 小镇阶段全局 ×1.2 | 20% |
| 特殊能力 | 解锁新建筑/新科技/新槽位 | 提前解锁水车 | 15% |
| 一次性消耗 | 立刻获得 Z 资源 | 立刻 +500 木材 | 15% |
| 功能性 | 离线效率 +X% / 存储 +X% | 离线效率 +10% | 10% |

### 2.2 稀有度分级

**推荐 4 档，不是 5 档。** 理由：单人美术产能有限，5 档视觉区分要做 5 套边框 + 5 种粒子，v2 做不完。

| 稀有度 | 颜色 | 视觉 | 掉落权重 | 数值幅度 |
| --- | --- | --- | --- | --- |
| 白（普通） | 灰边框 | 静态边框 | 60% | +5% ~ +10% |
| 蓝（稀有） | 蓝边框 + 微光 | 30% | +15% ~ +25% |
| 紫（史诗） | 紫边框 + 粒子 | 9% | +30% ~ +50% |
| 橙（传说） | 橙边框 + 脉冲光效 | 1% | +100% 或特殊能力 |

> v1 只做白/橙两档（占位），v2 加蓝紫。橙的脉冲光效用 Phaser Tween 做，不另画帧。

### 2.3 槽位设计

**推荐：建筑槽为主，小人槽为辅。**

| 槽位 | 数量 | 理由 |
| --- | --- | --- |
| 建筑槽 | 每个关键建筑（篝火/仓库/市场/宫殿）1 个 | 建筑数量可控（~20 个），UI 放得下 |
| 小人槽 | v2.5 才做，每个小人 1 个 | v1 小人最多 20 个（04_总览 §2.7 已冻结），UI 爆炸；v2.5 后再说 |
| 全局槽 | 3 个（任何道具可挂，全局生效） | 这是"遗物"槽，见方案 C |

**为什么不做"每个小人 3-5 个槽位"：**
- 小人一多（v2 后 50+），UI 就要画 50×5=250 个槽位，单人开发扛不住。
- 小人槽的收益和"直接加 buff"没区别，玩家记不住"这个小人装了什么"。

## 3. 五个候选方案

### 方案 A：极简局内掉落

**是什么：**
小人干活（砍树/采浆果/搬货）时有 1% 概率掉一个道具。道具掉落后自动生效，不用玩家装备。全局内最多同时生效 5 个道具，掉新的顶掉最旧的。

**道具池：** 20 个固定道具，每局从池里随机掉。

**肉鸽感：** 弱。玩家不需要做 build 决策，掉落是被动的。

| 维度 | 评估 |
| --- | --- |
| 开发量 | ~3 人天（掉率表 + 自动生效逻辑 + 20 个道具数据） |
| 肉鸽感 | ★★☆☆☆ |
| 挂机匹配 | ★★★★★（挂机自动掉，不用操作） |
| 数值风险 | 中（掉率要调，不然 1% 太低玩家无感） |
| 优点 | 最省，不破坏现有系统 |
| 缺点 | 没有"build"感，玩家不会为掉落兴奋 |

---

### 方案 B：装备槽 + 局内 build

**是什么：**
小人干活掉道具，掉后进背包。玩家点关键建筑 → 弹出槽位 → 把道具拖上去装备。装备后该建筑产出加成。

**道具池：** 50 个，分白/蓝/紫/橙 4 档。

**肉鸽感：** 中。玩家有"我要凑什么 build"的决策，但 build 自由度有限（槽位就那几个）。

| 维度 | 评估 |
| --- | --- |
| 开发量 | ~10 人天（背包 UI + 拖拽 + 装备生效 + 50 个道具 + 稀有度视觉） |
| 肉鸽感 | ★★★☆☆ |
| 挂机匹配 | ★★★★☆（挂机掉，上线后整理） |
| 数值风险 | 高（50 个道具的组合爆炸，数值平衡难做） |
| 优点 | 有 build 深度，Loop Hero 式爽感 |
| 缺点 | 开发量大，50 个道具数值要逐个调 |

---

### 方案 C：遗物 + 局外永久收集（主策划推荐）

**是什么：**
通关一次火箭后，掉 1 个"遗物"——这个遗物**永久解锁**，进入遗物图鉴。下一局开始时，玩家从已解锁遗物里**选 3 个**作为开局 buff。遗物不随局重置，是"局外肉鸽"。

**关键：** 局内不掉落，只在通关时结算。当前存档的稳定性不被破坏。

**道具池：** 60 个遗物，分 4 稀有度。每通关 1 次解锁 1 个新遗物，选 3 个开局。

**肉鸽感：** 强，但来自"局间选择"，不是"局内随机"。类似 Hades 的 Mirror / Dead Cells 的永久升级。

| 维度 | 评估 |
| --- | --- |
| 开发量 | ~8 人天（遗物图鉴 UI + 开局选 3 个的 UI + 60 个遗物数据 + 生效逻辑） |
| 肉鸽感 | ★★★★☆ |
| 挂机匹配 | ★★★★★（和 Prestige 天然契合，每轮选 3 个 buff 开局） |
| 数值风险 | 低（遗物效果设计时就定死，不随机掉落） |
| 优点 | 和 04e 的 Prestige 循环完美结合；不破坏当前存档；有"下局我要试试这个"的动机 |
| 缺点 | 局内没有随机惊喜，老玩家可能觉得"不够肉" |

---

### 方案 D：商人 + 商店刷新

**是什么：**
每 10 分钟商人来一次，随机卖 3 个道具（用资源买）。不做掉落，不做装备槽，道具买了立刻生效（一次性消耗）。

**道具池：** 30 个一次性消耗道具。

**肉鸽感：** 弱。商人卖什么是随机的，但玩家用不用是理性决策。

| 维度 | 评估 |
| --- | --- |
| 开发量 | ~4 人天（商人士兵 + 商店 UI + 30 个一次性道具） |
| 肉鸽感 | ★★☆☆☆ |
| 挂机匹配 | ★★★★☆（定时来，上线看到商人） |
| 数值风险 | 低（一次性消耗，不叠加） |
| 优点 | 简单，有"商人来了要不要买"的决策 |
| 缺点 | 不是真正的肉鸽，更像"商店刷新" |

---

### 方案 E：地图迷雾 + 探索

**是什么：**
地图边缘有迷雾。派小人去探索，探索发现宝箱/遗迹/道具。新区域解锁新建筑/新科技。

**道具池：** 不固定，和地图生成绑定。

**肉鸽感：** 强。每局地图不一样，探索过程有惊喜。

| 维度 | 评估 |
| --- | --- |
| 开发量 | ~20 人天（迷雾战争地图 + 探索派工 UI + 宝箱/遗迹事件 + 地图生成器） |
| 肉鸽感 | ★★★★★ |
| 挂机匹配 | ★★☆☆☆（要主动派小人，挂机不探索） |
| 数值风险 | 中（探索收益要平衡，不然玩家全去探索不生产） |
| 优点 | 最有"肉鸽味"，探索发现的惊喜感最强 |
| 缺点 | 开发量最大；和挂机节奏冲突（挂机玩家不探索） |

## 4. 获取方式候选对比

用户明确说"获取方式还没想好"。这一节把 6 种获取方式放一张表对比，每个方案从里面挑 1-2 种组合。

| 获取方式 | 开发量 | 肉鸽感 | 挂机匹配 | 数值风险 | 适合哪个方案 |
| --- | --- | --- | --- | --- | --- |
| **A. 随机掉落**（小人干活概率掉） | 低（2 人天） | 中 | 高（挂机自动掉） | 中（掉率要调） | 方案 A、B |
| **B. 探索发现**（派小人探迷雾） | 高（15 人天） | 高 | 中（要主动） | 低（可控） | 方案 E |
| **C. 商人交易**（用资源换） | 低（2 人天） | 低 | 高（定时来） | 低 | 方案 D |
| **D. 任务/成就奖励** | 低（1 人天） | 无 | 高 | 无（固定） | 所有方案通用 |
| **E. 星尘兑换**（通关货币买） | 低（1 人天） | 无 | 高 | 低（可控） | 方案 C |
| **F. 世界种子生成**（同 seed 同道具池） | 中（3 人天） | 中 | 高 | 中 | 方案 B、E |

**主策划判断：**
- 纯挂机游戏的最佳获取方式是 **A（掉落）+ C（商人）+ E（星尘兑换）**——都是"被动来，不操作"。
- B（探索）和 F（种子生成）是肉鸽味最重的，但开发量和挂机节奏都要权衡。
- D（成就奖励）是任何方案都该有的"保底"——保证玩家至少能拿到几个道具，不会一局空手。

## 5. 与现有系统结合：5 个具体道具例子

无论最终选哪个方案，这 5 个道具都是"必须有的样板"。它们覆盖了道具作用于：资源 / 建筑 / 小人 / 科技 / 阶段跃迁 / 星尘。

### 道具 1：【白·燧石片】属性增益
- **效果**：当前所有采集工人（伐木工/采集工/石匠）效率 +10%。
- **作用于**：小人。
- **生效方式**：装备到"工人手套槽"（方案 B）或开局选 3 个遗物之一（方案 C）。
- **数值**：和 04c 的 `tech_multiplier` 走同一通道，不新开乘法器——避免数值策划 §5.3 的叠乘爆炸。

### 道具 2：【蓝·永燃火把】特殊能力
- **效果**：篝火升级，夜晚浆果产出不衰减（原是"生火"科技效果，现在变成可解锁的道具效果）。
- **作用于**：建筑。
- **生效方式**：挂到篝火的建筑槽。
- **注意**：这个道具让玩家提前 1 个科技节点拿到夜晚加成——**和 04_总览 §1.13"v1 科技树纯线性"冲突**，列入待裁决（第 10 章）。

### 道具 3：【紫·古代蓝图】解锁新建筑
- **效果**：在阶段 2 提前解锁"水车"建筑（原本是阶段 3 科技）。
- **作用于**：科技/建筑解锁。
- **生效方式**：通关后作为遗物解锁，下局开局选。
- **风险**：跳过科技树会破坏"阶段门控"设计——04c §0.3 说"门控靠科技不靠时间"，这个道具相当于让玩家花钱跳门。**列为待裁决。**

### 道具 4：【橙·星尘核心】一次性消耗
- **效果**：立刻获得 50 星尘（对齐 04c §1.7 星尘公式）。
- **作用于**：转生/星尘。
- **生效方式**：商人出售（方案 D）或探索宝箱（方案 E）。
- **平衡**：50 星尘 = ×5.0 全局倍率（按加法公式），这个数值很强，所以必须是橙（1% 掉率），不能泛滥。

### 道具 5：【紫·商人地图】功能性
- **效果**：下一次商人来访时，所有道具价格 -50%。
- **作用于**：商人系统。
- **生效方式**：一次性消耗，用了就没。
- **设计意图**：给"商人来的时候没钱"的玩家一个"等等再买"的理由。

## 6. 肉鸽元素引入程度

这一节回答用户的第 4 个硬性要求。

### 6.1 道具池多大、每局抽多少

| 方案 | 道具池总量 | 每局获得 | 每局生效 |
| --- | --- | --- | --- |
| A 极简掉落 | 20 | 5-10 个 | 同时最多 5 个 |
| B 装备槽 | 50 | 10-15 个 | 装备 5-8 个 |
| C 局外遗物 | 60 | 通关解锁 1 个 | 开局选 3 个 |
| D 商人 | 30 | 每 10 分钟买 1-3 个 | 一次性消耗 |
| E 探索 | 不固定 | 每次探索 1-3 个 | 装备/消耗 |

### 6.2 每局道具组合差异有多大

| 方案 | 随机性 | 说明 |
| --- | --- | --- |
| A | 弱随机 | 池子小，几次就掉完了 |
| B | 中随机 | 50 个池子，build 有差异但不大 |
| C | 强随机（局间） | 60 个遗物选 3 个，组合空间 C(60,3)=34220，足够每局不一样 |
| D | 弱随机 | 商人卖什么随机，但玩家用不用是理性决策 |
| E | 强随机 | 地图完全不一样 |

**关键判断：** 方案 C 的"局间随机"是挂机游戏最舒服的肉鸽强度——它让玩家"每轮 Prestige 有新鲜体验"，但不破坏当前存档的稳定增长。

### 6.3 是否纳入世界种子

| 方案 | 是否受 seed 影响 | 理由 |
| --- | --- | --- |
| A | 否 | 池子固定，掉率固定 |
| B | 是（v2.5） | seed 决定初始道具池组成 |
| C | 否 | 遗物是永久解锁，和 seed 无关 |
| D | 否 | 商人卖什么用独立 RNG |
| E | 是（核心） | seed 决定地图布局，自然决定道具位置 |

### 6.4 道具是否影响数值期望

**这是关键边界：**
- 如果道具影响数值期望（即"欧皇玩家 5 小时通关、非酋 20 小时"），那就不是"软种子"，是"硬随机"——挂机玩家会觉得不公平。
- **主策划立场：道具不应该影响通关时间超过 ±20%。**

| 方案 | 数值期望影响 | 说明 |
| --- | --- | --- |
| A | ±10% | 小 buff，差距小 |
| B | ±30% | 50 个道具组合，可能出强力 build |
| C | ±15% | 开局 3 个遗物，每局选法不同但都是"已解锁"，可控 |
| D | ±5% | 一次性消耗，不长期叠加 |
| E | ±40% | 探索路线不同，收益差大 |

## 7. 对 500h 时长纵深的影响

对齐 04e 的 500h 分解表，道具系统怎么融入：

### 7.1 计入图鉴

04e §3.2 已定图鉴 86 个。道具/遗物系统**增加 20 个图鉴条目**：
- 12 个稀有遗物（紫/橙）
- 8 个"传说道具"（成就解锁）

图鉴总量从 86 → 106 个。时长贡献从 45h → 50h（+5h）。

### 7.2 计入成就

04e §3.3 已定 48 个成就。道具系统**加 5 个成就**：
- 收集 10 个遗物
- 收集全部 20 个传说道具
- 单局同时装备 5 个紫装
- 从商人买过 100 次
- 探索发现 50 个宝箱

成就总量从 48 → 53 个。时长贡献从 25h → 28h（+3h）。

### 7.3 是否新增时长块

**不新增独立时长块。** 道具系统嵌入到已有的 Prestige 循环里：
- 原来每轮 Prestige 给"新图鉴"（04e §3.1）
- 现在每轮 Prestige 给"新遗物"（方案 C）
- 两者合并，不另算时长

**500h 总数不变**，只是图鉴和成就的内部构成调整。

## 8. v1 / v2 边界与人天预估

| 版本 | 做什么 | 人天 | 对应方案 |
| --- | --- | --- | --- |
| **v1** | 不做道具系统。只在存档 schema 留 `relics_unlocked: string[]` 字段 | 0.5 人天（写类型） | 无 |
| **v2** | 方案 C 最小闭环：通关掉 1 个遗物 → 遗物图鉴 → 下局选 3 个开局 | 8 人天 | C |
| **v2.5** | 方案 D 商人系统 + 扩展遗物池到 60 个 | 6 人天 | C + D |
| **v3** | 方案 B 装备槽（如果用户想要更强肉鸽） | 10 人天 | B |
| **v3** | 方案 E 探索/迷雾（如果用户想要最强肉鸽） | 20 人天 | E |

**为什么 v1 不做：**
- 04_总览 §1.13 已冻结"v1 科技树纯线性"。
- v1 范围是 itch.io 教学关（前 3 阶段），加道具会分散精力。
- v1 的核心任务是"把小人干活的爽点打磨好"，道具是锦上添花，不是雪中送炭。

## 9. 主策划推荐

### 9.1 推荐组合：C 为主 + D 为辅

**方案 C（局外遗物）做主线，方案 D（商人）做补充。**

| 理由 | 说明 |
| --- | --- |
| 和 04e Prestige 循环完美契合 | 每轮通关给 1 个遗物 = 原来"给新图鉴"的升级 |
| 不破坏当前存档稳定 | 局内不随机，局间才选 |
| 开发量可控 | 8+6=14 人天，单人业余 ~3 周 |
| 数值风险低 | 遗物效果设计时定死，不随机掉落 |
| 肉鸽感足够 | 60 选 3 的组合空间 34220，足够每局不一样 |

### 9.2 为什么不选其他方案

- **A 极简掉落**：太弱，玩家无感。作为方案 C 的补充（局内偶尔掉个白装）可以，单独做不行。
- **B 装备槽**：build 深度好，但 50 个道具数值平衡要 04c 花 1 个月，单人扛不住。推到 v3。
- **D 商人**：单独做肉鸽感太弱，作为方案 C 的补充（卖一次性消耗品）很好。
- **E 探索**：肉鸽味最浓，但开发量 20 人天 + 和挂机节奏冲突。v3 再说。

### 9.3 备选推荐（如果用户觉得 C 不够"肉"）

**C + B 混合：** 局外遗物（C）+ 局内白/蓝装掉落（B 的弱化版）。
- 局内只掉白/蓝装（不做紫/橙），掉落后自动生效，不做装备 UI。
- 局外通关给遗物，开局选 3 个。
- 这样既有局内小惊喜，又有局间 build 决策。
- 开发量：8 + 3 = 11 人天。
