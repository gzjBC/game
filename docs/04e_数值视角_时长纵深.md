## 1. 500h 时长构成总表

**结论：500h = 主线 18h + 转生循环 42h + 戴森球冲刺 22h + 全图鉴 200h + 全成就 100h + 挑战模式 118h。**

| 模块 | 时长 (h) | 占比 | 说明 |
|---|---|---|---|
| 主线首次通关 | 18 | 3.6% | 04c 第 4.4 节已定 |
| 转生循环（15 次） | 42 | 8.4% | 见第 2 节衰减曲线 |
| 戴森球冲刺 | 22 | 4.4% | 成本从 1e15 下调到 1e10（见第 3 节） |
| 全图鉴（200 项） | 200 | 40% | 见第 4 节 |
| 全成就（50 个） | 100 | 20% | 见第 5 节 |
| 挑战模式（每日 + 竞速） | 118 | 23.6% | 见第 6 节 |
| **合计** | **500** | **100%** | |

> 设计意图：主线只占 3.6%，500h 的纵深靠**收集 + 成就 + 挑战**撑起来，而不是靠"被迫重复挂机"。这符合挂机游戏的现代设计（Kittens Game / Melvor 的 endgame 也是收集驱动）。

## 2. 转生循环数值

### 2.1 星尘公式（沿用 04c，修正取值）

04c 原定公式：

```
stardust_earned = floor( log10(total_rare_ore_collected) )
global_multiplier = 1 + 0.10 × stardust_owned
```

**修正点**：04c 附录 B 标注的 `floor(log10(rare_ore)/2)` 太弱（每次只给 4 点），这里**改回不除 2**——每次通关按 rare_ore 量级给星尘，第 N 次通关累计 rare_ore ~10^(N+7)，即第 N 次获得 `N+7` 点星尘。

```
stardust_earned_on_run(N) = N + 7
stardust_cumulative(N)    = (N-1)(N+14) / 2     # 前 N-1 次累计
multiplier_on_run(N)      = 1 + 0.10 × stardust_cumulative(N)
run_duration(N)           = 18 / multiplier_on_run(N)
```

### 2.2 衰减曲线（PowerShell 实算）

| 第 N 次通关 | 累计星尘 | 倍率 | 本轮时长 | 累计时长 |
|---|---|---|---|---|
| 1（首次） | 0 | ×1.00 | 18.00 h | 18.0 h |
| 2 | 8 | ×1.80 | 10.00 h | 28.0 h |
| 3 | 17 | ×2.70 | 6.67 h | 34.7 h |
| 4 | 27 | ×3.70 | 4.86 h | 39.5 h |
| 5 | 38 | ×4.80 | 3.75 h | 43.3 h |
| 6 | 50 | ×6.00 | 3.00 h | 46.3 h |
| 7 | 63 | ×7.30 | 2.47 h | 48.8 h |
| 8 | 77 | ×8.70 | 2.07 h | 50.9 h |
| 9 | 92 | ×10.20 | 1.76 h | 52.7 h |
| 10 | 108 | ×11.80 | 1.53 h | 54.2 h |
| 11 | 125 | ×13.50 | 1.33 h | 55.6 h |

| 15 | 203 | ×21.30 | 0.85 h | 59.6 h |
| 16 | 225 | ×23.50 | 0.77 h | 60.4 h |

### 2.3 软上限（边际收益为 0）

```
run_duration(N) < 0.5 h  ⟺  18 / (1 + 0.10 × (N-1)(N+14)/2) < 0.5
                         ⟺  (N-1)(N+14) > 340
                         ⟺  N ≈ 21
```

- **硬软上限定在第 16 次**：本轮时长 < 1 h，再转就是"5 分钟一局"的刷分模式，对 500h 主线无贡献。
- 第 17 次以后进入"自由刷分"，不计入 500h 设计目标。
- **结论：转生循环 = 首次 18h + 15 次转生 42.4h = 60.4h**，其中 42h 计入 500h 构成。

## 3. 数值增长数量级上限 & 戴森球调整

### 3.1 为什么 1e15 必须下调

04c 原定戴森球成本 `1×10¹⁵ 稀有矿物`。按太空阶段基础产出：

```
钻井平台 0.01/s × 10 座 = 0.1/s
T = 1e15 / 0.1 = 1e16 秒 ≈ 3.17 亿年
```

即使叠到第 16 次通关倍率 ×23.5，仍需 ~1300 万年——**单次游戏内不可达**。

### 3.2 调整方案（三件事同时做）

| 调整项 | 原值 | 新值 | 理由 |
|---|---|---|---|
| 戴森球成本 | 1e15 | **1e10** | 落到"可冲刺"量级 |
| 新增 v2 建筑：戴森球骨架 | 无 | **每座 500 稀有矿物/s** | v2 专属，Prestige 后解锁 |
| 骨架建筑数量 | — | 10 座（g=1.15） | 配合星尘倍率 |

### 3.3 戴森球冲刺时长验算

第 16 次通关后状态：

```
累计星尘       = 225
全局倍率       = ×23.5
钻井平台 30 座 = 0.3/s
戴森球骨架 10 座 = 5000/s
基础总产出     = 5000.3/s
倍率后产出     = 5000.3 × 23.5 = 117,507/s

T_dyson = 1e10 / 117,507 = 85,101 秒 ≈ 23.6 h
```

→ **戴森球冲刺 22–24 h**，计入 500h 构成。待调：如果实测 > 30h，把骨架 base 从 500/s 提到 800/s。

### 3.4 数字增长数量级上限

| 阶段 | 最大资源量级 | 对应建筑/事件 |
|---|---|---|
| v1（原始/村庄/小镇） | 1e4（工具） | 行会科技 5000 工具 |
| v2 主线单次 | 1e8（稀有矿物） | 发射台 |
| v2 戴森球 | 1e10（稀有矿物） | 终极建筑 |
| v2 Prestige 累积 | 1e12（历史累计） | 星尘统计 |

**break_infinity.js 支撑能力：**

- double 上限 ~1e308，break_infinity.js 可安全覆盖到 1e300。
- 本游戏 v2 最大数字 ~1e12，**远在安全区内**，不需要担心溢出。
- 真正的风险不是溢出，是 **UI 可读性**——1e12 以上纯数字串玩家读不动。

**UI 缩写格式（必须现在定）：**

```
< 1e3   : 原始数字（如 847）
1e3–1e6 : K / M（847 K / 12.3 M）
1e6–1e9 : M / B
1e9–1e12: B / T
1e12+   : aa / ab / ac / ... / az / ba / bb ...  (标准 -illion 缩写)
```

- 到 1e12 用 T，1e15 用 aa，1e18 用 ab——这是 Antimatter Dimensions 通用格式。
- **不需要扩展到 e300**，因为本游戏 v2 最大才 1e12，留 e300 给 v3 再说。

## 4. 图鉴 / 收集系统数值

### 4.1 图鉴结构

**总计 200 项，分 6 大类对应 6 阶段，每类 ~33 项：**

| 阶段 | 图鉴项数 | 解锁类型分布 |
|---|---|---|
| 原始 | 33 | 建筑 10 + 资源 8 + 人口 5 + 事件 10 |
| 村庄 | 33 | 同上 |
| 小镇 | 34 | 同上 |
| 城市 | 33 | 同上 |
| 国家 | 33 | 同上 |
| 太空 | 34 | 同上 |

### 4.2 单项解锁时间

| 解锁类型 | 典型门槛 | 单项耗时 |
|---|---|---|
| 建筑图鉴 | 建造 1 次该建筑 | 5 分钟 |
| 资源图鉴 | 累计产出 1e6 某资源 | 30 分钟 |
| 人口图鉴 | 累计招募 N 人口 | 1 小时 |
| 事件图鉴 | 触发随机事件（概率） | 2 小时（需反复刷） |

**加权平均：**

```
T_entry_avg = 0.1×5min + 0.3×30min + 0.3×60min + 0.3×120min
            = 0.5 + 9 + 18 + 36 = 63.5 分钟 ≈ 1.05 h/项
```

### 4.3 全图鉴总时间

```
T_compendium = 200 × 1.05 h ≈ 210 h
```

取整 **200 h**（部分图鉴项在主线/转生中自然解锁，不重复计入）。

## 6. 挑战模式数值

### 6.1 每日挑战

- 规则：每日 0 点刷新固定种子 + 1 个 debuff（强度 ×1.2–×1.5）。
- 平均耗时：每次 20–30 分钟。
- 全年活跃：365 天 × 0.3 h ≈ 110 h（活跃玩家约参与 60% 天数）。

### 6.2 种子竞速

- 种子池：v1 放出 10 个经过数值验证的种子，最优通关时间 4–6h。
- 排行榜：按"首次通关时间"排序，不记总游玩时长。
- 参与耗时：每次 5h × 参与 2 次 ≈ 8 h。

### 6.3 挑战模式总计

```
T_challenge = 110 h（每日） + 8 h（竞速） = 118 h
```

## 8. 500h 构成最终验算

```
T_total = T_main + T_prestige + T_dyson + T_compendium + T_achievements + T_challenge
        = 18     + 42          + 22      + 200           + 100              + 118
        = 500 h  ✓
```

**自洽性检查：**

1. 单人业余开发能否测完？主线 18h + 转生 60h = 80h，开发者周末 4 个下午可测完一轮完整流程。✓
2. 朋友试玩 20 分钟不劝退？前 5 分钟生火（04c 已验算），15 分钟到村庄，20 分钟看到小镇曙光。✓
3. 数字上限是否在 break_infinity 安全区？v2 最大 1e12，远小于 1e308。✓
4. 戴森球真的能摸到？第 16 次通关后 22h 冲刺可达。✓
5. 500h 会不会变成"重复挂机"？主线 + 转生只占 12%，88% 靠收集/成就/挑战。✓
