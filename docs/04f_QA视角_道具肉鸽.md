# 《High》QA 视角：道具/物品系统 + 肉鸽玩法（04f）

> 2026-09-17 · 设计方向未定，本文从 QA 立场给出候选方案 + 测试成本 + 风险，供策划选型时参考。
> 复用已确认基础设施：注入 RNG（04d §8.3）、注入时钟（04d §6.2）、meta/run 分层（04e §4.4）、SaveBackend 抽象（04e §4.3）。不推翻 04d/04e 任何 GWT 用例。

## 1. 道具随机性怎么测

### 1.1 前提：掉落必须走注入 RNG

04d §8.3 已经规定所有 `Math.random()` 换成注入 RNG。道具系统必须遵守，否则"同 seed 同掉落"这条根本测不了。

| # | 场景 | 断言 |
| --- | --- | --- |
| G1 | 注入 seed=S0，击杀/采集触发掉落 ×100 次 | 两次跑完全部掉落 ID 序列完全一致 |
| G2 | 同 seed=S0，改一个无关变量（UI 配色） | 掉落序列不变——证明没偷用裸 Math.random |
| G3 | 稀有度 roll：5% 传说 | 跑 10000 次 | 命中率 4%~6%（95% 置信区间） |
| G4 | 背包已满（30/30） | 触发掉落 | 不崩溃、不吞掉掉落、不掉到虚空；按规则丢弃或进临时邮箱 |
| G5 | 背包满 + 同时掉 3 个 | 三个都按同一规则处理，不出现"第一个被吞，后两个进背包" |
| G6 | 稀有度 roll 到概率边界（0% / 100%） | 0% 永不出；100% 必出；不出现浮点误差导致 0% 出了 1 个 |
| G7 | 道具效果叠加溢出：同时装备 100 个"产出+1%" | 总加成 = 100%（加法）或 ×2.7（乘法），按设计；**不得**因为浮点累加成 99.99999% 或 101.00001% |
| G8 | 道具效果 × 星尘加成 × 科技加成 | 三者乘法叠加后数值不爆 Infinity（500h 压力测试，04e §6 P0） |
| G9 | 道具效果有冷却/持续时间 | 用注入时钟快进，冷却结束、到期消失，不靠真实时间 |

### 1.2 背包满的处理策略（策划要选一个）

| 方案 | 测试成本 | QA 评价 |
| --- | --- | --- |
| A. 满了直接丢 | 低 | 玩家会觉得"我啥都没了"，差评 |
| B. 满了进临时邮箱（30 天） | 中 | 推荐；多一个邮箱系统要测，但玩家不丢东西 |
| C. 满了不让打 | 高 | 不推荐，肉鸽感全无 |

**QA 推荐 B**。如果选 B，邮箱本身又是一个新系统，要追加：邮箱满了怎么办、跨周目邮箱保留吗、邮件过期删不删。

## 2. 候选获取方式的测试成本

> 设计方向未定。下面列五种主流获取方式，每种标测试成本（低/中/高），策划选型时一并考虑。

| 获取方式 | 机制 | 测试成本 | QA 评价 |
| --- | --- | --- | --- |
| **① 随机掉落** | 采集/战斗按概率掉 | **中** | 必须走注入 RNG；概率用例 G3 覆盖；肉鸽味最足 |
| **② 探索发现** | 迷雾地图走到某格才解锁 | **中** | 迷雾地图本身要 seed 可重现（见 §2.1）；v1 没战斗系统，探索 = 走到格子 |
| **③ 商人交易** | 每隔 N 小时刷库存，用资源换 | **中** | 库存刷新必须走 seed + 日期，不能纯随机；否则玩家改时间刷商人 |
| **④ 星尘兑换** | 周目结束后用星尘永久解锁 | **低** | 确定性最高，纯查表；但要测价格曲线回归 |
| **⑤ 合成/配方** | A+B=C，背包组合 | **高** | 组合爆炸，N 个道具 C(N,2) 种配方，要写自动化遍历 |

### 2.1 各方案的关键用例

#### ① 随机掉落（成本：中）
- [ ] 概率表符合数值策划给的公式（G3）。
- [ ] 同一 seed 掉落序列一致（G1）。
- [ ] 背包满的边界（G4/G5）。
- [ ] 不掉"当前阶段拿不到"的道具（M1 玩家不会掉"M5 稀有矿道具"）。

#### ② 探索发现（成本：中）
| # | 场景 | 断言 |
| --- | --- | --- |
| EX1 | 同 seed ×2 | 迷雾地图上所有"可探索点"位置完全一致 |
| EX2 | 走到某格 | 第一次走触发发现；第二次走不重复触发 |
| EX3 | 探索点被建筑占了 | 不冲突；或设计成"不能在探索点上建"，启动时就标红 |
| EX4 | 探索点奖励是道具 | 走过去必给；不走不给；不因为重进游戏刷新 |

#### ③ 商人交易（成本：中）
| # | 场景 | 断言 |
| --- | --- | --- |
| SH1 | 同一天 ×3 次打开商人 | 库存完全一致（seed + 日期决定） |
| SH2 | 改系统时间到明天 | 库存刷新；但不能反复改时间刷同一天（用"上次访问日期"挡，同 04e §8.6） |
| SH3 | 商人卖的道具价格 | 价格曲线和数值表对得上；不出现"M1 商人卖 M5 道具" |
| SH4 | 买了一半刷新 | 已买的不回滚；库存刷新不影响已持有 |

#### ④ 星尘兑换（成本：低）
| # | 场景 | 断言 |
| --- | --- | --- |
| SC1 | 星尘够 | 兑换按钮可点；星尘扣减正确 |
| SC2 | 星尘不够 | 按钮置灰；不出现"扣成负数星尘" |
| SC3 | 兑换后立即转生 | 永久加成生效（这是星尘兑换的意义） |
| SC4 | 价格曲线：第 N 次买同一项价格 ×1.5 | 10 次后价格 = 基础 × 1.5^9，数学上对；不因为浮点变 1.50000001 |

#### ⑤ 合成配方（成本：高，v1 不建议）
- [ ] N 个道具两两组合，自动化遍历所有合法配方。
- [ ] 非法组合（A+B 不是配方）：不消耗材料，不报错。
- [ ] 合成后材料消失、成品进背包。
- **QA 建议**：v1 不做合成。组合爆炸的测试成本和收益不成正比，v2 再说。

### 2.2 QA 推荐组合

v1 只做 ① + ④：
- **① 随机掉落**给肉鸽味，② 探索发现作为彩蛋少量加。
- **④ 星尘兑换**给长期目标，确定性高，测试便宜。
- ③ 商人 v1 可选，做的话必须用 seed+日期锁库存。
- ⑤ 合成 v1 不做。

## 3. 道具 × 现有系统交互测试矩阵

> 这是道具系统最容易出 bug 的地方：道具是"加在现有系统上的一层"，现有系统改了道具可能就漏。

### 3.1 道具作用于资源

| # | 场景 | 断言 |
| --- | --- | --- |
| R1 | 使用"浆果 +100"道具 | 资源 +100，不因为 break_infinity 浮点变 99.99999 |
| R2 | 使用"所有资源 ×2"道具 | 大数资源 ×2 不溢出 Infinity |
| R3 | 资源已满 | 道具使用后不溢出（clamp 到上限），不浪费 |
| R4 | 道具效果是"未来 1 小时产出 ×2" | 用注入时钟快进 1 小时，倍率真的生效；过期后回到正常 |
| R5 | 倍率道具 ×2 同时叠 3 个 | 是 ×4 还是 ×8？按设计；不因为浮点误差变成 ×3.99999 |

### 3.2 道具作用于建筑

| # | 场景 | 断言 |
| --- | --- | --- |
| B1 | 对茅草房使用"升级"道具 | 建筑等级 +1；如果本来要花 100 木头，道具效果是"免费用"还是"折扣"？写死 |
| B2 | 道具效果还在，把建筑拆了 | 道具效果**消失还是残留**？QA 推荐：随建筑拆除消失（否则会出现"拆了房子 buff 还在"的 bug） |
| B3 | 道具是"全建筑 +10%" | 建新建筑时，新建筑是否也吃到这个 buff？按设计写死 |
| B4 | 阶段切换后旧建筑拆了换新房 | 全局 buff 是否延续到新建筑？写死 |

### 3.3 道具作用于小人

| # | 场景 | 断言 |
| --- | --- | --- |
| V1 | 给小人 A 装备"采集+50%"道具 | A 采集速度真的变快 |
| V2 | 小人 A 退休/走了 | 道具**回到背包还是跟着消失**？QA 推荐：回到背包（否则玩家会骂"我道具没了"） |
| V3 | 小人 A 死了（如果有死） | 同上，回背包 |
| V4 | 同时给小人 A 装备 5 个道具 | 效果叠加正确；UI 上 5 个槽位都亮 |
| V5 | 小人改名后道具 | 道具跟随"小人 ID"，不跟随"名字"——否则重名会穿 |

### 3.4 道具作用于阶段跃迁

| # | 场景 | 断言 |
| --- | --- | --- |
| ST1 | 正在用"产出+50%"道具时，阶段切换 | 道具持续时间**继续走还是重置**？写死 |
| ST2 | 阶段跃迁后，M1 道具对 M5 建筑还有效吗？ | QA 推荐：跨阶段不失效（否则玩家会觉得"我刚买的就废了"） |
| ST3 | 跃迁后新建筑 | 是否继承全局 buff？和 B3 一致 |

### 3.5 道具作用于星尘 / 转生

| # | 场景 | 断言 |
| --- | --- | --- |
| P1 | 转生时背包里有道具 | 按设计：**消耗品清空，永久解锁保留**——这和 04e §4.4 的 meta/run 分层对齐 |
| P2 | 道具效果是"本周目产出+50%" | 转生后正确清零 |
| P3 | 道具效果是"永久产出+5%" | 转生后保留，进 meta 层 |
| P4 | 转生时玩家正在使用时效道具 | 时效道具是消失还是延续？写死 |

**核心原则**：道具系统必须从第一天就明确分类——**消耗品（run 层）/ 永久解锁（meta 层）/ 时效 buff（run 层，按时间走）**。不分类就是灾难。

## 4. 小白玩家体验

### 4.1 第一次掉道具是什么时候？

- [ ] 推荐时机：**M2 村庄早期**，玩家刚建完第一个茅草房。不要 M1 就掉（信息量太大），不要 M3 才掉（肉鸽感太晚）。
- [ ] 第一次掉落必须是"明显有用"的（如"立刻 +200 浆果"），不要给一个晦涩的"下一次采集概率翻倍"。
- [ ] 第一次掉落要有一次性弹窗："你捡到了一个奇怪的石头！点这里看看"——教会他背包在哪。

### 4.2 道具说明文案怎么写不困惑

| 道具 | ❌ 坏文案 | ✅ 好文案 |
| --- | --- | --- |
| 浆果袋 | "一个神奇的袋子" | "立即获得 200 浆果" |
| 加速药水 | "时光的力量" | "接下来 5 分钟，所有产出 ×2" |
| 招募令 | "领袖的召唤" | "立即招募 1 个免费小人" |
| 永久锤子 | "工匠的祝福" | "**永久**：所有建筑升级 -10% 价格" |

**文案规则**：
- 数字永远写出来，不写"一些""大量"。
- 永久 vs 临时必须在标题上标出来。
- 不写比喻、不写风味文，第一句就是效果。

### 4.3 道具槽位 UI 在哪？

- [ ] 主界面右下角一个小背包图标，不占主视野。
- [ ] 点开是一个面板，格子按"消耗品 / 永久解锁 / 装备中"分三类。
- [ ] 鼠标悬停显示完整文案；手机长按显示。
- [ ] 不要在主界面摊开一排道具栏——挂机游戏 UI 已经够挤了。

## 5. P0 / P1 / P2 风险清单

### P0（不解决做不了道具系统）

- [ ] **必须复用注入 RNG**：道具掉落不走注入 RNG，整个肉鸽系统不可测，改个 bug 都不知道改没改对。这是硬阻塞。
- [ ] **道具三层分类（消耗品/永久/时效）从第一天定**：不分层，转生时道具保留逻辑必崩。
- [ ] **背包满的处理方案先选**：不选就开发，必出"道具凭空消失"投诉。
- [ ] **大数叠加溢出**：500h 玩家身上叠几百个道具加成，e308 风险比 04e §6 P0 还大。

### P1（不解决会被骂）

- [ ] **道具效果 × 现有系统的优先级**：道具和科技、星尘加成叠加顺序写死，否则不同人算出来不一样。
- [ ] **建筑拆除/小人退休时道具归属**：B2/V2 的"回背包 vs 消失"方案要拍板。
- [ ] **商人库存防改时间**：和离线收益一个坑，改时间刷商人。
- [ ] **道具说明文案审核**：数值改了文案没改是挂机游戏最常见的吐槽点，要做"数值→文案"自动生成，不手写。

### P2（锦上添花）

- [ ] **道具图鉴**：和 04e §2 的图鉴系统合并，不单独做。
- [ ] **道具分享/截图**：v1 不做。
- [ ] **道具排序/筛选**：100+ 道具后才有需求，v1 不做。
- [ ] **合成配方**：v1 不做（见 §2.2）。
