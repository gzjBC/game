## 1. 稀有度概率曲线

### 1.1 五档概率（挂机游戏基调）

| 稀有度 | 概率 | 单道具增益 | 贡献 |
|---|---|---|---|
| 白 Common | 70% | +5%（单资源） | 3.50% |
| 绿 Uncommon | 20% | +15%（单资源） | 3.00% |
| 蓝 Rare | 7% | +35%（全局） | 2.45% |
| 紫 Epic | 2.5% | +75%（全局） | 1.88% |
| 橙 Legendary | 0.5% | +150%（全局） | 0.75% |

**单次掉落期望增益 = 11.58%。**

### 1.2 为什么不是"白 +5%、橙 +500%"

- 若橙 +500%，单个橙就把戴森球时间从 22h 压到 3.7h，**直接破坏 04e 的 500h 结构**。
- 挂机游戏的稀有度意义是"收藏 + 小提升"，不是"抽到就毕业"。
- 橙 +150% 已经是单道具上限——1 个橙 ≈ 13 个白的期望值，但不会越级秒关。

### 1.3 软上限（防崩盘核心）

```
item_global_cap = 2.0      # 道具全局倍率硬上限 ×2.0
item_max_active = 10       # 最多 10 个不同名道具同时生效
item_same_name_stack = 0   # 同名不叠加
```

- 凑满 ×2.0（即额外 +100%）后，再掉道具只进图鉴，不生效。
- **为什么是 ×2.0 不是 ×3.0？** 04e 第 3.3 节已验算：
  - ×2.0 时戴森球 22h → 11h（可接受，戴森球仍是 22h 冲刺的一半）
  - ×3.0 时戴森球 22h → 7.3h（过短，玩家 1 周摸透终局）

## 2. 各获取方式数值对比

### 2.1 对比基准

**目标：凑满道具软上限（+100% 全局倍率），各方式需要多少时间/资源？**

| 获取方式 | 单次成本 | 期望增益/次 | 凑满 +100% 所需 | 性价比 |
|---|---|---|---|---|
| 随机掉落 | 0（挂机） | 11.58%/个，2 个/h | **4.5 小时挂机** | 中 |
| 探索发现 | 500 食物 + 200 木材 | 24.5%/个，2 次/h | **2 小时**（耗资源） | 高 |
| 商人交易 | 256 金币/件（期望） | 11.58%/件，0.375 件/h | **23 小时**（攒钱） | 低 |
| 星尘兑换 | 50 星尘/橙 | 150%/个 | **4 个橙**（第 16 次通关后） | 高但滞后 |

### 2.2 逐项验算

**随机掉落：**
- 挂机每小时掉 2 个道具。
- 期望增益/drop = 11.58%。
- 凑满 +100% 需要 100/11.58 ≈ 9 个 drop。
- 9 / 2 = **4.5 小时挂机**。
- 设计意图：玩家第 2 周目前 5 小时就能凑满，之后道具系统对进程无影响。

**探索发现：**
- 探一次迷雾区：500 食物 + 200 木材。
- 农场 2 食物/s → 500 食物 = 250 秒；每小时可探 ~14 次（但受木材约束，实际 2 次/h）。
- 探索保底 +1 档稀有度：白 20% / 绿 50% / 蓝 20% / 紫 8% / 橙 2%。
- 期望增益 = 0.2×5% + 0.5×15% + 0.2×35% + 0.08×75% + 0.02×150% = 24.5%。
- 凑满 +100% 需要 ~5 次探索，**2 小时**（含资源采集）。

**商人交易：**
- 价格表：白 50 / 绿 200 / 蓝 800 / 紫 3000 / 橙 10000 金币。
- 期望价格 = 0.7×50 + 0.2×200 + 0.07×800 + 0.025×3000 + 0.005×10000 = **256 金币/件**。
- 每 8 小时刷新 3 件，即 0.375 件/h。
- 凑满 +100% 需要 ~9 件 = 24 小时商人周期。
- 实际：玩家不会等商人，会直接攒 10000 金币买指定橙（3 小时市场产出）。
- **结论：商人是"指定购买"渠道，不是随机渠道。**

**星尘兑换：**
- 橙道具定价 50 星尘。
- 第 16 次通关后累计 225 星尘，可换 4 个橙。
- 4 × 150% = ×6.0 倍率——**远超软上限 ×2.0**！
- **刹车：星尘兑换的橙道具最多 1 个生效**，其余 3 个进图鉴收藏。

## 3. 道具数值平衡

### 3.1 五个具体道具草案

| 稀有度 | 名称 | 效果 | 数值 |
|---|---|---|---|
| 白 | 旧斧头 Rusty Axe | 浆果产出 +5% | 单资源，原始阶段 |
| 绿 | 铜制镰刀 Copper Sickle | 食物产出 +15% | 单资源，村庄阶段 |
| 蓝 | 水力磨坊 Water Mill | 全产出 +35% | 全局，小镇阶段 |
| 紫 | 自动流水线 Auto Assembly | 工人效率 +75% | 全局，城市阶段 |
| 橙 | 时空折叠 Temporal Fold | 全局产出 +50%，离线效率 +10% | 全局，太空阶段 |

> **修正**：橙道具从 +150% 下调到 **+50%**。
> 理由：若橙 +150%，玩家抽到 2 个橙就 ×4.0，远超 ×2.0 软上限。
> 改成 +50% 后，需要 4 个紫或 2 个橙才凑满 ×2.0，节奏更稳。

### 3.2 叠加规则

```
# 同名：不叠加（抽到 2 个旧斧头，只生效 1 个）
item_same_name_stack = 0

# 不同名：最多 10 个同时生效
item_max_active = 10

# 全局倍率：硬 cap ×2.0
item_global_cap = 2.0

# 超过软上限：道具进图鉴，不生效（不删除，保留收藏价值）
overflow_mode = "codex_only"
```

### 3.3 对 break_infinity.js 数字膨胀的影响

**结论：无影响。**

- 道具倍率最多 ×2.0，是**乘法器**不是**数量级**。
- 戴森球成本 1e10 不变，只是时间从 22h 缩到 11h。
- 不会让 1e10 变成 1e5——那是数量级崩坏，道具系统不允许设计成那样。
- 真正会让数字膨胀的是"产出 ×1e6"这类道具，**本文明确禁止**：所有道具增益 ≤ +150%，禁止数量级跳跃。

## 4. 对 500h 时长的影响

### 4.1 新增时长

| 模块 | 新增时长 | 说明 |
|---|---|---|
| 道具图鉴收集 | 40 h | 50 个道具 × 0.8h/个 |
| 道具相关成就 | 10 h | 5 个新成就 |
| **合计** | **50 h** | |

**500h 构成更新：**

```
原: 18 + 42 + 22 + 200 + 100 + 118 = 500 h
新: 18 + 42 + 22 + 200 + 100 + 118 + 50(道具) - 50(图鉴压缩) = 500 h
```

- 图鉴 200 项里**分 50 项给道具**（5 稀有度 × 10 种），剩余 150 项给原有的建筑/资源/人口/事件。
- 总时长不变，只是把"非道具图鉴"从 200h 压到 150h，道具占 50h。

### 4.2 主线首次 18h 会不会变短？

**不会。** 刹车：

```
# 首次主线（第 1 次通关）锁定道具栏
item_slot_unlock_after_run = 2   # 第 2 周目才解锁道具栏
```

- v1 首次通关**没有道具系统**——玩家裸打 18h。
- 第 2 周目开始道具栏解锁，但此时玩家已有星尘倍率 ×1.8，主线已经缩到 10h，道具再 +50% 也只是 6.7h，不破坏 04e 的衰减曲线。

### 4.3 图鉴重分配

| 图鉴类别 | 原项数 | 新项数 |
|---|---|---|
| 建筑 | 60 | 45 |
| 资源 | 40 | 30 |
| 人口 | 30 | 25 |
| 事件 | 40 | 30 |
| 道具 | 30 | 70 |
| **合计** | **200** | **200** |

## 5. 风险数字与刹车

### 5.1 最坏情况

**场景：玩家第 16 次通关后，带满道具进戴森球冲刺。**

| 项 | 数值 |
|---|---|
| 星尘累计倍率 | ×23.5 |
| 道具软上限 | ×2.0 |
| 总倍率 | ×47.0 |
| 戴森球原时间 | 22 h |
| 戴森球新时间 | 22 / 47 = **0.47 h ≈ 28 分钟** |

**这是问题。** 道具让戴森球从 22h 缩到 28 分钟，终局感崩塌。

### 5.2 刹车方案（三选一，数值推荐 B）

| 方案 | 做法 | 戴森球时间 | 评价 |
|---|---|---|---|
| A | 道具不生效于戴森球阶段 | 22 h（不变） | 简单，但玩家觉得道具没用 |
| **B** | **道具倍率在太空阶段衰减 50%** | **22 / (23.5 + 1.0) = 0.92 h ≈ 55 分钟** | **推荐：道具前期爽，后期不崩** |
| C | 戴森球成本上调到 5e10 | 22h（不变） | 破坏 04e 已确认数字 |

**推荐方案 B 的实现：**

```
# 太空阶段道具衰减
item_efficiency_in_stage = {
  1: 1.0, 2: 1.0, 3: 1.0,
  4: 0.8, 5: 0.6, 6: 0.3   # 太空阶段道具只生效 30%
}
```

- 前 5 阶段道具 100% 生效（玩家爽）。
- 太空阶段道具只生效 30%——×2.0 软上限实际只给 ×1.3。
- 戴森球时间 = 22 / (23.5 × 1.3) = 0.72 h ≈ 43 分钟。
- **仍然偏短**，再补一刀：戴森球冲刺**禁止带道具**，必须裸打。

### 5.3 最终刹车（推荐组合）

1. **全局倍率硬 cap ×2.0**（前 5 阶段生效）。
2. **太空阶段道具衰减到 30%**。
3. **戴森球冲刺禁止带道具**（最后 22h 裸打）。
4. 同名不叠加，最多 10 个生效。
5. 首次主线无道具，第 2 周目解锁。
6. 橙道具 +50% 封顶，禁止 +500% 级跳跃。
